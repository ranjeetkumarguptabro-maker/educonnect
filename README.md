# EduConnect

EduConnect is a comprehensive web application designed to connect students, teachers/professors, and organizations for academic collaboration, project teaming, and opportunities.

## Features

- **7-Page Complete Flow**:
  - **Page 1: Onboarding Landing**: Vector illustrations, 3 floating category badges, 3D stacked books (*Learn, Build, Connect*), and quick sign-in links.
  - **Page 2: Role Selection**: Interactive selection for Students, Teachers/Professors, and Organizations.
  - **Page 3: User Details**: Field of study & college year selectors, goal checkboxes, and custom vector character artwork.
  - **Page 4: Interests**: 12 selectable topic chips (AI, Web Dev, Cybersecurity, Sustainability, etc.) with profile settings callout.
  - **Page 5: Final Details**: In-depth involvement options, weekly availability dropdown, and organization contact toggle.
  - **Page 6: Engagement**: Talent matching, project posting, event promotion options, and optional contact form.
  - **Page 7: Main Dashboard & Project Feed**: Full project feed featuring interactive video players, topic tags, bookmarking, social reactions, search, sub-category filtering, and 5-item mobile bottom navigation.

- **Dual View Modes**:
  - **Single Page Interactive Mode**: Navigate seamlessly step-by-step with interactive buttons.
  - **Stacked View ("Show All")**: View all 7 screens simultaneously on a continuous scrollable layout.
  - **Desktop Frame Mode**: Toggle between a realistic mobile device frame and expanded responsive layout.

## Tech Stack

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Google Fonts** (Plus Jakarta Sans & Caveat)
- **Vanilla JavaScript** (Zero external heavy dependencies)

## Getting Started

Simply open `index.html` in any modern web browser:

```bash
open index.html
```

Or run a local static server:

```bash
npx serve .
# or
python3 -m http.server 8000
```
